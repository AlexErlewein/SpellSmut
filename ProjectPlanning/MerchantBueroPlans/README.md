# MerchantBueroPlans

This directory contains the implementation plan for adding a Merchant section to GraufurterBuergerBuero.

## Contents

| File | Description |
|------|-------------|
| `MERCHANT_PLAN.md` | Complete implementation plan |

## Quick Summary

This plan adds merchant functionality to the NPC Creator allowing:
- Creating NPCs configured as merchants
- Defining merchant inventory (items for sale)
- Setting price multipliers for item types
- Exporting to CFF categories 2041, 2042, 2047
