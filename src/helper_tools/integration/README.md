# Integration Tools

This directory contains tools for integrating different systems and components of the SpellForce modding toolkit.

## Tools

- **cff_editor_itm_integration.py** - Integration between CFF editor and ITM (Item) systems

## Usage

Run from project root using UV:

```bash
uv run python src/helper_tools/integration/cff_editor_itm_integration.py
```

## Purpose

Integration tools handle:
- Data synchronization between different systems
- Format conversion and mapping
- Cross-system compatibility
- Data import/export operations
