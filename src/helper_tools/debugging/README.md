# Debugging Tools

This directory contains debugging and diagnostic utilities for troubleshooting various aspects of the SpellForce modding tools.

## Tools

- **debug_gui.py** - GUI debugging utilities and diagnostics
- **debug_icon_browser.py** - Icon browser debugging and testing
- **debug_item_ui_mapping.py** - Item-UI mapping debugging tools

## Usage

Run from project root using UV:

```bash
uv run python src/helper_tools/debugging/debug_gui.py
```

## Purpose

These tools help diagnose and fix issues with:
- GUI applications
- Icon loading and display
- Item-UI mapping resolution
- Asset path resolution
